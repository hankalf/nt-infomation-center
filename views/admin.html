Sections

The headings resources are grouped under on the public site. Use the arrows to change the order.

Departments

One per line. Used for the "Department" filter, people, resources and the access checklist.

Roles

One per line. These appear in the "My role" filter and can be ticked on each resource.

People

Everyone listed here appears in the org chart. Set Reports to to build the chart, and tick Who to Ask to also show them as a key contact. Staff logins are managed separately under Employees.

Org chart preview

Updates as you type. Remember to save.

New starter access checklist

Pick a department and role to see every system, folder and mailbox that person needs, then print it. To keep a saved record for a specific person, use Employees → Onboarding.

Access items

Everything a person might need access to. Tag each item with the departments and roles that need it. Leave both empty if everyone needs it. Only admins can see this list.

Each employee gets their own login. When you add someone, you'll get a temporary password to give them. They must choose their own password the first time they sign in.

Site details & logo

No logo

Security & reviews

Documents whose "Last reviewed" date is older than this show up on the Dashboard as overdue.

📣 Announcements

Banners shown at the top of the home page, for example "New fire exit route from Monday". Staff can dismiss them. Leave "Show until" empty to keep one up until you remove it.

💾 Backup & restore

Download a zip with everything: documents, content, people, logins, activity and usage stats. Keep it somewhere safe, such as a shared drive. Store it carefully, because it contains staff login details.

⬇ Download backup

Restoring replaces all current content with the backup. The data from just before the restore is kept in a before-restore-… folder on the server in case you need it back.
